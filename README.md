# 彩雲之南・雲南八日旅遊手冊（PWA）

2026/11/21–11/28 昆明、大理、麗江、香格里拉行程手冊。純 HTML/CSS/JS，沒有建置步驟。

## 本機預覽

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory yunnan-handbook
```

開 <http://127.0.0.1:8765>。網址加 `?now=2026-11-24T15:30` 可預覽旅途中「今日行程」的樣子（時間以 UTC+8 計）。

## 裝到手機

Service worker 只在 HTTPS（或 localhost）下運作，所以要先把整個資料夾放到任一 HTTPS 靜態主機（GitHub Pages、Netlify、Cloudflare Pages 皆可）。

- Android Chrome：開啟後點「安裝」或選單裡的「加到主畫面」。
- iPhone Safari：分享 →「加入主畫面」。

第一次開啟會把頁面、插圖與字型子集存進手機，之後沒網路也能用。天氣與匯率需要連線，離線時顯示上次結果。

## 修改內容

- 行程、航班、行李清單、緊急電話都在 `data.js`。
- 改既有檔案：重新部署即可，手機下次開啟會換新版。
- 新增、改名或刪除檔案：同步更新 `sw.js` 的 `ASSETS`，並把 `VERSION` 加一。

## 注意

- 行程依 Trip.com 產品 72467351 的參考行程整理，實際時間、飯店與車次以出團通知為準。
- 勾選、旅記、導遊電話只存在各自手機的瀏覽器裡，不會上傳。
